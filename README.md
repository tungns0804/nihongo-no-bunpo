## Thêm bài mới

1. Copy file [templates/grammar-template.md](templates/grammar-template.md) vào thư mục cấp độ tương ứng (ví dụ `N4/`).
2. Đặt tên file bằng mẫu ngữ pháp tiếng Nhật (dùng kanji nếu mẫu đó thường viết bằng kanji), bỏ dấu 〜 ở đầu: `てもいい.md`, `訳ではない.md`.
3. Thêm một dòng vào bảng của cấp độ đó trong file này.
