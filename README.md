# 日本語の文法 — Ngữ pháp tiếng Nhật

Tổng hợp các mẫu ngữ pháp tiếng Nhật theo cấp độ JLPT, kèm cách dùng, ví dụ có furigana và bài tập nhỏ.

## Ký hiệu

Cách gọi các thể giống sách みんなの日本語:

| Ký hiệu | Ý nghĩa | Ví dụ với 書きます |
|---|---|---|
| N | Danh từ | |
| Vます形 | Phần đứng trước ます | 書き |
| V辞書形 | Thể từ điển | 書く |
| Vて形 | Thể て | 書いて |
| Vた形 | Thể た | 書いた |
| Vない形 | Phần đứng trước ない | 書か |
| 普通形 | Thể thông thường (辞書形・ない・た・なかった) | 書く・書かない・書いた・書かなかった |

| Ký hiệu | Ý nghĩa | Ví dụ |
|---|---|---|
| いA | Tính từ đuôi い (giữ nguyên い) | 高い |
| いA(〜い) | Tính từ đuôi い, bỏ い | 高 |
| なA | Tính từ đuôi な (không kèm な) | 静か |

3. Thêm một dòng vào bảng của bài đó trong file này (và trong `README.md` của thư mục bài, nếu có).
