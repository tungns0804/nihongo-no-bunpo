## Ký hiệu

| Ký hiệu | Ý nghĩa | Ví dụ |
|---|---|---|
| N | Danh từ | 本 |
| Vます形 | Phần đứng trước ます | 書き（ます） |
| V辞書形 | Thể từ điển | 書く |
| Vて形 | Thể て | 書いて |
| Vた形 | Thể た | 書いた |
| Vない形 | Phần đứng trước ない | 書か（ない） |
| 普通形 | Thể thông thường | 書く・書かない・書いた・書かなかった |
| いA | Tính từ đuôi い | 高い |
| いA（〜い） | Tính từ đuôi い, bỏ い | 高 |
| なA | Tính từ đuôi な, không kèm な | 静か |
