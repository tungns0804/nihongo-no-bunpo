# Vて<ruby>形<rt>けい</rt></ruby>

**Giáo trình:** みんなの日本語 初級Ⅰ · [第14課](README.md)  
**Cấp độ:** N5  
**Ý nghĩa:** Cách chia thể て

## Cấu trúc

| Nhóm | Quy tắc | Ví dụ |
|---|---|---|
| I | い・ち・り → **って** | <ruby>買<rt>か</rt></ruby>います → <ruby>買<rt>か</rt></ruby>って、<ruby>待<rt>ま</rt></ruby>ちます → <ruby>待<rt>ま</rt></ruby>って、<ruby>帰<rt>かえ</rt></ruby>ります → <ruby>帰<rt>かえ</rt></ruby>って |
| I | み・び・に → **んで** | <ruby>飲<rt>の</rt></ruby>みます → <ruby>飲<rt>の</rt></ruby>んで、<ruby>呼<rt>よ</rt></ruby>びます → <ruby>呼<rt>よ</rt></ruby>んで、<ruby>死<rt>し</rt></ruby>にます → <ruby>死<rt>し</rt></ruby>んで |
| I | き → **いて** | <ruby>書<rt>か</rt></ruby>きます → <ruby>書<rt>か</rt></ruby>いて |
| I | ぎ → **いで** | <ruby>急<rt>いそ</rt></ruby>ぎます → <ruby>急<rt>いそ</rt></ruby>いで |
| I | し → **して** | <ruby>貸<rt>か</rt></ruby>します → <ruby>貸<rt>か</rt></ruby>して |
| I | Ngoại lệ | <ruby>行<rt>い</rt></ruby>きます → **<ruby>行<rt>い</rt></ruby>って** |
| II | ます → **て** | <ruby>食<rt>た</rt></ruby>べます → <ruby>食<rt>た</rt></ruby>べて、<ruby>見<rt>み</rt></ruby>ます → <ruby>見<rt>み</rt></ruby>て |
| III | | します → して、<ruby>来<rt>き</rt></ruby>ます → <ruby>来<rt>き</rt></ruby>て |

## Cách dùng

- Thể て không đứng một mình mà kết hợp với nhiều mẫu câu: 〜てください、〜ています、〜てもいいです、〜てから...

## Ví dụ

1. <ruby>言<rt>い</rt></ruby>います → <ruby>言<rt>い</rt></ruby>って  
   → Nhóm I (い → って).
2. <ruby>読<rt>よ</rt></ruby>みます → <ruby>読<rt>よ</rt></ruby>んで  
   → Nhóm I (み → んで).
3. <ruby>出<rt>だ</rt></ruby>します → <ruby>出<rt>だ</rt></ruby>して  
   → Nhóm I (し → して).

## Lưu ý

> [!WARNING]
> <ruby>行<rt>い</rt></ruby>きます là ngoại lệ duy nhất của đuôi き: **<ruby>行<rt>い</rt></ruby>って**, không phải ~~<ruby>行<rt>い</rt></ruby>いて~~.
