# Vた<ruby>形<rt>けい</rt></ruby>

**Giáo trình:** みんなの日本語 初級Ⅰ · [第19課](README.md)  
**Cấp độ:** N5  
**Ý nghĩa:** Cách chia thể た (quá khứ thông thường)

## Cấu trúc

| Nhóm | Quy tắc | Ví dụ |
|---|---|---|
| I | Giống thể て, đổi て → **た**, で → **だ** | <ruby>書<rt>か</rt></ruby>いて → <ruby>書<rt>か</rt></ruby>いた、<ruby>飲<rt>の</rt></ruby>んで → <ruby>飲<rt>の</rt></ruby>んだ、<ruby>行<rt>い</rt></ruby>って → <ruby>行<rt>い</rt></ruby>った |
| II | Bỏ ます + **た** | <ruby>食<rt>た</rt></ruby>べます → <ruby>食<rt>た</rt></ruby>べた、<ruby>見<rt>み</rt></ruby>ます → <ruby>見<rt>み</rt></ruby>た |
| III | | します → した、<ruby>来<rt>き</rt></ruby>ます → <ruby>来<rt>き</rt></ruby>た |

## Cách dùng

- Thể た được tạo từ thể て bằng cách thay て／で bằng た／だ.
- Dùng trong các mẫu: 〜たことがあります、〜たり〜たりします、〜たほうがいいです、〜たら...

## Ví dụ

1. <ruby>泳<rt>およ</rt></ruby>ぎます → <ruby>泳<rt>およ</rt></ruby>いで → <ruby>泳<rt>およ</rt></ruby>いだ  
   → Nhóm I, ぎ.
2. <ruby>待<rt>ま</rt></ruby>ちます → <ruby>待<rt>ま</rt></ruby>って → <ruby>待<rt>ま</rt></ruby>った  
   → Nhóm I, ち.
3. <ruby>来<rt>き</rt></ruby>ます → <ruby>来<rt>き</rt></ruby>て → <ruby>来<rt>き</rt></ruby>た  
   → Nhóm III.
